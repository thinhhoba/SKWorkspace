01 — Chạy song song Sapo

Adapter Sapo đồng bộ 2 chiều: pull đơn/SP/khách/tồn về SK Workspace; push đơn mới sang Sapo. Lưu external_id để đối chiếu, last_synced_at để incremental sync.

02 — Tích hợp hóa đơn

meInvoice phát hành HĐ ra, InBot tự động hút HĐ vào, HĐĐT TCT đối chiếu với CQT. Tất cả lưu PDF/XML trên MinIO, log đầy đủ trong integration_logs.

03 — Deploy 1 VPS

docker compose up -d dựng Postgres + Redis + MinIO + Next.js. Nginx reverse proxy + Let's Encrypt. Backup DB cron hàng ngày. PWA qua next-pwa — không cần app native.
